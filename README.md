# Dungeon Cafe

**NOTE: if you are a 3am reviewer, the. do remember that this is a group project and only Fynr1x or FaizeenHoque's 7h or so have been submitted to 3am, not pratikkumararyan**

A little game I've been working on in Godot :D

Dungeon Cafe is a dungeon-themed game where you can move around, fight enemies, and pick up items. It's still pretty early in development, so there's a lot I wanna add and improve, but the basic gameplay systems are coming together.

I'm mostly making this to mess around with game development, learn how things work, and hopefully turn it into something actually fun to play :))

## How to Play

Find the game [on itch!](https://faizeenhoque.itch.io/dungeon-cafe)

## Gameplay

Right now, the game has a few basic systems working:

- Player movement **(WASD keys)**
- Attacking and combat **(Spacebar)**
- Enemies
- Item pickups

Nothing too crazy yet, but it's a start. I'll keep adding stuff as I work on it.

## How to run locally

You'll need Godot 4.7 to open the project.

1. Clone the repository:

   ```bash
   git clone https://github.com/pratikkumararyan/dungeon_cafe.git
   ```

2. Open Godot and import the project folder.
3. Open the project and press `F6` to run the current scene, or `F5` to run the main scene.
